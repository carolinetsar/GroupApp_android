## Built: GroupApp — Android app for group gatherings

Created a complete, from-scratch Android Studio project at `workbuddy-ai/GroupApp`.

**Stack:** Kotlin 1.9.24, Jetpack Compose (BOM 2024.06.00), Material 3, Navigation Compose 2.7.7,
AGP 8.5.2, Gradle 8.7, minSdk 26 / compileSdk 34, kotlinx-serialization 1.6.3.

**Features implemented:** category picker (кафе / совместная покупка / аренда / прогулка / другое),
feed with search + category filters + city selector, create-gathering form (place, date/time, price,
discount, people needed), join/leave, detail screen with participants + organizer rating + reviews,
"My gatherings" (created / joined tabs), profile with rating, reviews and editing, city picker with
20 Russian cities + geolocation via `LocationManager` (no Play Services dependency).

**Persistence:** whole app state serialized to JSON in SharedPreferences (`LocalStore`), seeded from
`DemoData` on first launch. Single source of truth is `GatheringRepository` (StateFlow) exposed via
`AppViewModel`.

**Environment note:** no JDK / Gradle / Android SDK on this machine, so the project could NOT be
compiled. Verified instead by static analysis: brace/paren balance, package-vs-directory match,
and every `com.groupapp.*` import resolving to a real declaration. Found and fixed one real
build-breaker this way (`Common.kt` had `package com.groupapp.ui` instead of `...ui.components`).

**Gotcha for next time:** `gradle-wrapper.jar` cannot be authored as text — it was downloaded from
`raw.githubusercontent.com/gradle/gradle/v8.7.0/gradle/wrapper/gradle-wrapper.jar`.
