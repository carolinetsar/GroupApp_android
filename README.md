# GroupApp

MVP Android-приложения для создания совместных сборов.

## Что уже работает

- просмотр сборов
- фильтрация по городу и категориям
- создание и удаление своего сбора
- присоединение к сбору и выход из него
- профиль пользователя
- отзывы и рейтинг
- раздел «Мои сборы»

## Технологии

- Kotlin
- Jetpack Compose
- Material 3

На данный момент данные хранятся локально. Серверная часть и полноценная авторизация ещё не подключены.

## Как открыть

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Android Studio.
3. Дождаться Gradle Sync.
4. Запустить проект на Android-эмуляторе или Android-устройстве.

## Совместимость

- minSdk: 26
- протестировано на эмуляторе Pixel 8, API 37.2

## Статус

MVP успешно собирается и запускается. Основные функции протестированы вручную.
